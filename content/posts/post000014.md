# 二 正文
这里采用调用函数的方案，而汇编传参一般通过提前扔进寄存器实现，这里因为要算除法所以放进```AX```了。  
首先我们写出```c++```的代码：
```cpp
    int num = 10086;
    char numstr[5] = {0};
    int i = 4;
    while(num > 0){
        numstr[i] = i % 10 + '0';
        num /= 10;
        --i;
    }
    for(int i = 0; i < 5; ++i){
        if(numstr[i] == 0) continue;
        cout << numstr[i];
    }
```
大概就这样。下面来解释一下为什么这么写。  
```21H```号中断里并没有直接输出整数的功能，但是有输出单个字符的功能，就是```02H```号功能，我们采取这种方案。  
而接下来，我们要考虑一个问题，就是数字在取余时得到的每一位数字实际上是倒着排列的，例如```10086```如果直接取余输出，会输出```68001```这种鬼畜玩意。因此我们采取了拿一个数组倒序去存每一位，最后正着输出的方案。  
大体思路定下来了我们可以开始尝试写代码。  
首先我们要把取余的每一位存在一个数组里。这个数组我们在数据段声明好。我们定义```PRINTINTEGER```方法，开始写代码。  
汇编中，除法是这样算的：把被除数放在```AX```里面，接着把除数放在任意一个寄存器里（虽然理论上是任意，但是主要还是常用的可以安全随意放数据的那几个），此处我们采用```BX```寄存器存放除数```10```。而除完的商放在```AX```中，余数放在```DX```中。  
按照这个原理，我们可以写出除法循环的代码：
```armasm
    LEA SI, NUMSTR + 4
    MOV BX, 10

    DIVISION:
    DIV BX
    ADD DL, 30H
    MOV [SI], DL
    DEC SI
    CMP AX, 0
    JA DIVISION
```
逐行分析一下，```LEA SI, NUMSTR + 4```就是把```SI```指向了```NUMSTR```数组的末尾（因为我们要倒序存储）。  
下面的```ADD DL, 30H```是加了```'0'```这个偏移量，因为输出字符要对应```ASCII```码表。  
接着```MOV [SI], DL```是把余数加```'0'```以后的结果放进数组，方便后续输出。  
下一步```DEC SI```就是自减，把下标往前挪。  
接着比较一下商```AX```和```0```的大小，如果大于```0```就继续循环，否则进行打印。  
接着我们来写打印的代码。这个也简单。  
```armasm
    LEA SI, NUMSTR

    PRINT:
    CMP [SI], 0
    JE CHECK
    MOV DL, [SI]
    MOV AH, 02H
    INT 21H
    CHECK:
    INC SI
    CMP SI, OFFSET NUMSTR + 4
    JNA PRINT
```
这一段也不难分析。首先还是把```NUMSTR```地址放进```SI```寄存器。接着进入PRINT循环。  
这里因为位数不确定，我们把数组初始化为```0```，所以这里先判断这一位是不是```0```（注意不是```'0'```），是的话直接跳到```CHECK```进行下标检查，否则进行输出，很简单的逻辑。  
最后加一个```0```的特判，如果是```0```直接输出```0```不走这些步骤了。  
大体的框架就这样，贴个代码，由于没有系统学习码风很乱：
```armasm
ASSUME CS:CODE, DS:DATA

DATA SEGMENT
    NUM DW 10086
    NUMSTR DB 5 DUP(0)
DATA ENDS

CODE SEGMENT
START:
    MOV AX, DATA
    MOV DS, AX

    MOV AX, NUM
    CALL PRINTINTEGER

    MOV AH, 4CH
    INT 21H

PRINTINTEGER PROC
    CMP AX, 0
    JE ZERO
    JNE NOTZERO

    ZERO:
    MOV DL, 30H
    MOV AH, 02H
    INT 21H
    RET

    NOTZERO:
    MOV BX, 10
    LEA SI, NUMSTR + 4
    
    DIVISION:
    XOR DX, DX
    DIV BX
    ADD DL, 30H
    MOV [SI], DL
    DEC SI
    CMP AX, 0
    JA DIVISION

    LEA SI, NUMSTR

    PRINT:
    CMP [SI], 0
    JE CHECK
    MOV DL, [SI]
    MOV AH, 02H
    INT 21H
    CHECK:
    INC SI
    CMP SI, OFFSET NUMSTR + 4
    JNA PRINT

    RET
PRINTINTEGER ENDP

CODE ENDS
END START
```
