对vector的简单实现

July 28, 2026

最近有些颓废，但也尝试了写点新东西。我找ai问了问意见，决定写个简单的vector出来。
其实我也没想到vector实现起来的原理并不复杂，以前看STL源码完全看不懂。
当然我没用std::allocator实现分配内存，我只用了new和delete。
简单写写笔记。

1.写在前面#

(1)学到的一些语法知识#

<1>const限定类方法#

之前我没有仔细研究过c++的class里各种限制，写这个算是学到一点新东西，就是在声明类方法如下：void f() {}时，如果创建的是const对象，需要在结尾加上一个const修饰符表明这个方法对于const对象可用（e.g. void f() const {}），以前还真没注意过。

<2>常引用传参#

这个其实我以前见过，但是我一直没搞懂什么意思，才知道它和普通传参的区别。
普通传参如void f(int x) {}，此时x是要进行拷贝的，如果说x不是简单的类型而是内部有一堆数据的类型，这里的拷贝开销会很大，所以采用如下形式：void f(const T& x) {}减少开销，这无疑是明智的，不用执行大量的构造函数，也省了内存。
这里的常引用传参实际上就是访问了传进来参数的数据，并且const限定了以只读形式访问，安全性up。

<3>指针加减法#

没想到我还能在这种基础问题上拿不准。
其实我之前没怎么写过指针相关操作，所以我一直以为指针减法减出来的是字节数，我还想除以sizeof(T)来着，问了ai才发现返回的已经是元素个数了。。。是我基础不扎实了。 还有一个衍生问题就是++和--运算符，对于一个简单类型的变量/指针来说，i++和++i（--同理）没什么区别，都是计算机的add指令之类的，但是对于指针，这个区别很大，主要在于i++需要执行构造函数，而++i不需要，这里又是开销的问题。所以以后我觉得还是把++作为“向后移动一位”的意思来理解吧。

<4>delete和delete[]的区别#

这个也是因为我不怎么写c++的指针相关内容导致的。
delete只释放了后面跟的一个对象的那一块内存，而delete[]释放了后面跟着的一大块内存。 我们这里扩容声明的新内存都是通过new[]的形式来声明的，内存头部已经存放了数组大小的数据，所以我们调用delete[]会自己释放到对应位置就停止，这才是正确的做法，不然内存堆得越来越多就炸了。

(2)防御性编程#

这一点的体现主要是在扩容的时候，开辟新内存以后不能直接释放旧内存，不然开辟失败了旧数据也丢了，风险很大，要等到开辟完毕以后再释放旧内存，这也是c++的设计哲学罢。

(3)size_t的用途#

size_t这东西实际上就是专门用来存储容器大小数据的类型，所以包括size()、capacity在内的方法返回值都是size_t，for循环遍历的时候如果不用iterator也要用size_t来声明循环变量。

2.基本功能#

vector实际上维护的是一块连续的内存，而我们只需要手动维护start，finish和end_of_storage指针。

(1)push_back#

push_back的逻辑很简单，首先检查finish == end_of_storage是否成立，如果成立说明需要扩容，不成立就直接添加元素。
扩容的时候不是在原基础上扩容，而是开辟新内存，因为原基础扩容可能访问到后续的危险内存，程序直接返回3221225477了。
我们可以申请一块新内存：T* new_mem = new T[new_capacity]，然后将数据一个一个放进new_mem里面，这样就完成了扩容。
new_capacity是依情况而定的，如果capacity() == 0那么new_capacity为1，否则直接翻倍。 无论是否扩容，我们都要执行*finish = val; ++finish的类似语句，这样一个push_back就完成了。

(2)insert和erase#

这俩玩意逻辑挺相似的。
insert同样要判断是否扩容，这里我们要获取旧的元素下标，因为如果扩容旧内存就直接失效了，我们用指针减法存下来index，扩容完毕以后用pos = start + index加回来就好。
而insert的移动元素是从后往前挪，从finish这个空位开始依次执行*it = *(it - 1)（别急，迭代器马上就说怎么实现的），这是防止元素覆盖问题。
腾出来相应的位置直接*pos = val就好了。很简单。最后++finish。
erase相对简单，它不用考虑扩容问题，只需要判断empty() || pos == finish并返回nullptr即可。
这里我们就要从前往后挪了，直接把那个位置的数据覆盖掉，最后执行--finish; finish->~T()（因为原来的finish前一位是有数据的，这里给它释放置空）。

(3)iterator#

迭代器其实就是一个T*指针，没什么好说的，对应的const版本也只是const T*指针。

(4) vector(const vector& other)构造函数以及operator=(const vector& other)运算符重载#

对于构造函数的实现，我们无需考虑自己赋值给自己的问题，所以我们可以直接开辟新内存往里存数据。
而等号的运算符重载需要考虑一下自己给自己赋值的问题，所以加一个this == &other判断就好了。

(5)其它基础功能#

别的功能都没什么好说的了，像是begin()和end()这些直接返回start和finish，重载operator[]只是算了个指针加法，没什么意思就不细说了。

3.总结#

写了这个简单vector以后，对于c++内存管理一类的内容有了一些新理解，也学到了一些编程上的技巧、策略。希望还能有这种学习的机会。
