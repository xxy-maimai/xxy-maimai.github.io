二 正文#

这里采用调用函数的方案，而汇编传参一般通过提前扔进寄存器实现，这里因为要算除法所以放进AX了。
首先我们写出c++的代码：

    int num = 10086;
    char numstr[5] = {0};
    int i = 4;
    while(num > 0){
        numstr[i] = i % 10 + '0';
        num /= 10;
        --i;
    }
    for(int i = 0; i < 5; ++i){
        if(numstr[i] == 0) continue;
        cout << numstr[i];
    }

大概就这样。下面来解释一下为什么这么写。
21H号中断里并没有直接输出整数的功能，但是有输出单个字符的功能，就是02H号功能，我们采取这种方案。
而接下来，我们要考虑一个问题，就是数字在取余时得到的每一位数字实际上是倒着排列的，例如10086如果直接取余输出，会输出68001这种鬼畜玩意。因此我们采取了拿一个数组倒序去存每一位，最后正着输出的方案。
大体思路定下来了我们可以开始尝试写代码。
首先我们要把取余的每一位存在一个数组里。这个数组我们在数据段声明好。我们定义PRINTINTEGER方法，开始写代码。
汇编中，除法是这样算的：把被除数放在AX里面，接着把除数放在任意一个寄存器里（虽然理论上是任意，但是主要还是常用的可以安全随意放数据的那几个），此处我们采用BX寄存器存放除数10。而除完的商放在AX中，余数放在DX中。
按照这个原理，我们可以写出除法循环的代码：

    LEA SI, NUMSTR + 4
    MOV BX, 10

    DIVISION:
    DIV BX
    ADD DL, 30H
    MOV [SI], DL
    DEC SI
    CMP AX, 0
    JA DIVISION

逐行分析一下，LEA SI, NUMSTR + 4就是把SI指向了NUMSTR数组的末尾（因为我们要倒序存储）。
下面的ADD DL, 30H是加了'0'这个偏移量，因为输出字符要对应ASCII码表。
接着MOV [SI], DL是把余数加'0'以后的结果放进数组，方便后续输出。
下一步DEC SI就是自减，把下标往前挪。
接着比较一下商AX和0的大小，如果大于0就继续循环，否则进行打印。
接着我们来写打印的代码。这个也简单。

    LEA SI, NUMSTR

    PRINT:
    CMP [SI], 0
    JE CHECK
    MOV DL, [SI]
    MOV AH, 02H
    INT 21H
    CHECK:
    INC SI
    CMP SI, OFFSET NUMSTR + 4
    JNA PRINT

这一段也不难分析。首先还是把NUMSTR地址放进SI寄存器。接着进入PRINT循环。
这里因为位数不确定，我们把数组初始化为0，所以这里先判断这一位是不是0（注意不是'0'），是的话直接跳到CHECK进行下标检查，否则进行输出，很简单的逻辑。
最后加一个0的特判，如果是0直接输出0不走这些步骤了。
大体的框架就这样，贴个代码，由于没有系统学习码风很乱：

ASSUME CS:CODE, DS:DATA

DATA SEGMENT
    NUM DW 10086
    NUMSTR DB 5 DUP(0)
DATA ENDS

CODE SEGMENT
START:
    MOV AX, DATA
    MOV DS, AX

    MOV AX, NUM
    CALL PRINTINTEGER

    MOV AH, 4CH
    INT 21H

PRINTINTEGER PROC
    CMP AX, 0
    JE ZERO
    JNE NOTZERO

    ZERO:
    MOV DL, 30H
    MOV AH, 02H
    INT 21H
    RET

    NOTZERO:
    MOV BX, 10
    LEA SI, NUMSTR + 4
    
    DIVISION:
    XOR DX, DX
    DIV BX
    ADD DL, 30H
    MOV [SI], DL
    DEC SI
    CMP AX, 0
    JA DIVISION

    LEA SI, NUMSTR

    PRINT:
    CMP [SI], 0
    JE CHECK
    MOV DL, [SI]
    MOV AH, 02H
    INT 21H
    CHECK:
    INC SI
    CMP SI, OFFSET NUMSTR + 4
    JNA PRINT

    RET
PRINTINTEGER ENDP

CODE ENDS
END START
